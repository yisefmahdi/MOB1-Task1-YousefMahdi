# تطبيق 04 - Article Screen

تطبيق شاشة المقال التوضيحي (Jetpack Compose tutorial) كأحد تمارين **Module 1** لمساق برمجة تطبيقات الهواتف النقالة 1.

- **اسم الطالب:** يوسف مهدي (Yousef Mahdi)
- **محتويات الواجهة:**
  - صورة البانر العلوية بعرض الشاشة الكامل.
  - عنوان المقال: `Jetpack Compose tutorial` بحجم 24sp وبادينج 16dp.
  - الفقرة الأولى (ملخص تعريفي) بمحاذاة أفقية متناسقة.
  - الفقرة الثانية (شرح تفصيلي) بخط منظم ومريح للقراءة.
- **المميزات:**
  - دعم التمرير التلقائي (`ScrollView`) لدعم مختلف مقاسات الشاشات.
  - دعم كامل للوضعين النهاري (`#FFF5EC`) والليلي (`#1E1005`).
  - زر تبديل تفاعلي سريع للوضعين أعلى الشاشة.
