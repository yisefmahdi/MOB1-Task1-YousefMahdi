# تطبيق بطاقة تهنئة عيد الميلاد (Birthday Card App)

مشروع تطبيقي لمساق **Android 1 - برمجة تطبيقات الهواتف النقالة** (النشاط الأول).

---

## 📱 تفاصيل التطبيق
- **اسم التطبيق:** Birthday Card
- **اسم الطالب (المرسل):** يوسف (From Yousef)
- **اسم الصديق (صاحب العيد):** فراس (Happy Birthday Feras!)
- **الصورة المستخدمة:** صورة الخلفية المرفقة بتنسيق متجاوب (CenterCrop).

---

## 🌓 دعم الوضعين (النهاري والليلي - Day & Night Mode)
تم تصميم التطبيق ليدعم الوضعين النهاري والليلي تلقائياً وبشكل احترافي ومطابق للمطلوب:
1. **الوضع النهاري (Light Mode):**
   - خلفية زاهية وساطعة بكامل ألوانها.
   - نص التهنئة باللون الداكن الأنيق (`#212121`).
   - نص التوقيع "From Yousef" باللون الأحمر الجذاب (`#E53935`).
2. **الوضع الليلي (Dark Mode):**
   - طبقة تظليل ناعمة ومريحة للعين فوق صورة الخلفية (`#6E000000`) دون إخفاء جمالية الصورة.
   - نص التهنئة يتحول تلقائياً إلى اللون الفاتح المريح (`#F2E6E6`).
   - نص التوقيع بلون أحمر مضيء ومناسب للخلفية الداكنة (`#FF4D4D`).
3. **زر تبديل مباشر (Toggle Button):**
   - تمت إضافة زر أعلى الشاشة للتبديل الفوري بين الوضع الليلي والنهاري بضغطة زر واحدة لتسهيل تقييم الأستاذ في الجامعة دون الحاجة لتغيير إعدادات الهاتف بالكامل.

## 🚀 كيفية تصدير ملف APK أونلاين (بدون الحاجة لتثبيت أندرويد ستوديو)

### الطريقة الأولى (الأسهل والأضمن): عبر GitHub Actions مجاناً
1. قم بإنشاء مستودع جديد (New Repository) على حسابك في GitHub.
2. ارفع مجلد المشروع كاملاً إلى المستودع.
3. تلقائياً سيبدأ إجراء (GitHub Action) المعرّف في `.github/workflows/build-apk.yml`.
4. بعد دقيقتين، ادخل على تبويب **Actions** ثم اختر آخر تشغيل، وستجد ملف الـ APK جاهزاً للتحميل باسم `BirthdayCard-Debug-APK`.

### الطريقة الثانية: عبر موقع Newly.app
1. استخدم الملف المضغوط الجاهز `BirthdayCard_Project.zip` الموجود بجانب المشروع.
2. افتح موقع [Newly.app](https://newly.app).
3. اختر خيار رفع مشروع Android ZIP.
4. انتظر لحظات لتحميل ملف الـ APK وتثبيته مباشرة على هاتفك.

### الطريقة الثالثة: عبر أندرويد ستوديو (محلياً)
- افتح المشروع من داخل Android Studio عبر: `File -> Open` ثم اختر مجلد `تطبيق الاول`.
- من القائمة العلوية اضغط: `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
