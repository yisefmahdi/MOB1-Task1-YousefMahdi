# تطبيق 05 - Business Card

تطبيق بطاقة الأعمال الشخصية (Business Card) كآخر تمارين **Module 1** لمساق برمجة تطبيقات الهواتف النقالة 1.

- **اسم المطور:** يوسف مهدي (Yousef Mahdi)
- **المسمى المهني:** Expert Web Developer
- **التصميم والمحتوى:**
  - شعار وأيقونة متطورة تعبر عن **برمجة الويب (Web Development)** مصممة بدقة عالية.
  - الاسم بخط أخضر زمردي بارز (`#3DDB84`).
  - قسم معلومات التواصل (الهاتف، حساب التواصل، البريد الإلكتروني) بأيقونات متناسقة ومحاذاة احترافية.
  - خلفية كحلية عميقة (`#0C1757`) مطابقة للأصل.
  - دعم الوضع الليلي والنهاري وزر التبديل التفاعلي السريع.
