### 1️⃣ تطبيق 01 - Birthday Card
- **الفكرة:** بطاقة تهنئة بعيد الميلاد لصديق مع دعم ميزة الوضعين النهاري والليلي (Day/Night Mode).
- **المرسل:** Yousef (From Yousef)
- **صاحب العيد:** Feras (Happy Birthday Feras!)
- **المميزات:** دعم كامل للوضعين النهاري والليلي تلقائياً مع زر تبديل سريع أعلى الشاشة.

---

### 2️⃣ تطبيق 02 - Task Done Screen
- **الفكرة:** شاشة إتمام المهام (Task Completed) بتصميم أنيق ومريح للعين.
- **النصوص:** `All tasks completed`، `Nice work!`، واسم الطالب `Yousef Mahdi`.
- **المميزات:** أيقونة إتمام المهام الشفافة وألوان خلفية مطابقة للأصل مع زر التبديل التفاعلي.

---

### 3️⃣ تطبيق 03 - Quadrant Screen
- **الفكرة:** تقسيم الشاشة إلى 4 أجزاء متساوية (Grid 2x2) بنسبة 50% لكل قسم باستخدام `LinearLayout Weights`.
- **الأقسام:** `Text composable`، `Image composable`، `Row composable`، `Column composable`.
- **المميزات:** ألوان شطرنجية متناسقة ومتطابقة في الوضعين النهاري والليلي.

---

### 4️⃣ تطبيق 04 - Article Screen
- **الفكرة:** شاشة مقال توضيحي حول Jetpack Compose مع بانر علوي وفقرات نصية متناسقة.
- **المميزات:** دعم التمرير السلس (`ScrollView`) مع دعم كامل للوضعين النهاري والليلي.

---

### 5️⃣ تطبيق 05 - Business Card
- **الفكرة:** بطاقة الأعمال الشخصية للمطور مع معلومات التواصل.
- **اسم المطور:** Yousef Mahdi
- **المسمى المهني:** Expert Web Developer
- **المميزات:**
  - تم استبدال أيقونة الأندرويد بأيقونة احترافية خاصة بـ **برمجة الويب (Web Development)** بدقة عالية.
  - الاسم بلون أخضر زمردي بارز (`#3DDB84`).
  - قسم وسائل التواصل: رقم الهاتف، حساب التواصل، البريد الإلكتروني.
  - خلفية كحلية ملكية عميقة (`#0C1757`) مطابقة للأصل.

---

### ⚙️ البناء السحابي التلقائي (CI/CD - GitHub Actions)
تم إعداد Workflow داخل المستودع بمجلد `.github/workflows/build-apk.yml`.  
يقوم GitHub Actions تلقائياً ببناء ملف الـ APK لكل من التطبيقات الـ 5 بشكل متوازي وسريع، وإتاحتها جميعاً للتحميل الفوري من تبويب **Actions**.
