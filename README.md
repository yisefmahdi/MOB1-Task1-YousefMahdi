### 1️⃣ تفاصيل تطبيق 01 - Birthday Card
- **فكرة التطبيق:** بطاقة تهنئة بعيد الميلاد لصديق مع دعم ميزة الوضعين النهاري والليلي (Day/Night Mode).
- **المرسل:** يوسف (From Yousef)
- **صاحب العيد:** فراس (Happy Birthday Feras!)
- **المميزات:**
  - دعم كامل للـ Day Mode والـ Dark Mode تلقائياً مع زر تبديل سريع أعلى الشاشة.
  - صورة خلفية متناسقة بأبعاد الشاشة (CenterCrop).

---

### 2️⃣ تفاصيل تطبيق 02 - Task Done Screen
- **فكرة التطبيق:** شاشة إتمام المهام (Task Completed) بتصميم أنيق ومريح للعين.
- **النصوص:**
  - `All tasks completed` (خط عريض 24sp).
  - `Nice work!` (خط عادي 16sp).
  - `Yousef Mahdi` (اسم الطالب بخط بارز وأنيق).
- **المميزات:**
  - أيقونة إتمام المهام الشفافة بدقة عالية.
  - ألوان خلفية مطابقة للأصل (Peach Cream للنهاري، و Warm Dark Brown لليلي).
  - زر تبديل تفاعلي سريع للوضعين النهاري والليلي.

---

### ⚙️ البناء السحابي التلقائي (CI/CD - GitHub Actions)
تم إعداد Workflow داخل المستودع بمجلد `.github/workflows/build-apk.yml`.  
يقوم GitHub Actions تلقائياً ببناء ملف الـ APK لكل تطبيق بشكل متوازي وإتاحتهما للتحميل الفوري من تبويب **Actions**.
