### 1️⃣ تفاصيل تطبيق 01 - Birthday Card
- **فكرة التطبيق:** بطاقة تهنئة بعيد الميلاد لصديق مع دعم ميزة الوضعين النهاري والليلي (Day/Night Mode).
- **المرسل:** يوسف (From Yousef)
- **صاحب العيد:** فراس (Happy Birthday Feras!)
- **المميزات الإضافية:**
  - دعم كامل للـ Day Mode والـ Dark Mode تلقائياً ومع زر تبديل سريع أعلى الشاشة.
  - صورة خلفية متناسقة مع أبعاد الشاشة بدون تشويه (CenterCrop).
  - خطوط واضحة وألوان متناسقة مع كلا الوضعين.

---

### ⚙️ البناء السحابي التلقائي (CI/CD - GitHub Actions)
تم إعداد Workflow داخل المستودع بمجلد `.github/workflows/build-apk.yml`.  
بمجرد عمل `push` إلى المستودع، يقوم GitHub Actions تلقائياً ببناء ملف الـ APK لكل تطبيق وإتاحته للتحميل الفوري من تبويب **Actions**.
